# 写入卡片

HINATA Go 支持向空白卡片写入 **Aime** 或 **Banapass** 卡号，使其可直接在支持的街机游戏上作为游戏卡使用。

::: tip 适用场景
* 为 HINATA 标准版附赠的空白卡写入卡号。
* 自行购买的兼容卡片写入卡号。
* 若你使用的是官方原装卡（如 Amusement IC、原装 Aime/BANA 卡），无需进行写入操作，直接使用即可。
:::

---

## 硬件与卡片要求

### 1. 支持的目标卡片
* **MIFARE Classic 1K 卡片（4 字节 UID）**。
* 必须是未加密扇区、具有默认或已知密钥的白卡/兼容卡。

::: warning ⚠️ 不支持的卡片
* **Amusement IC（四社通）卡片**：属于 FeliCa 或 MIFARE Plus/DESFire 等安全芯片，不支持作为写入目标。
* **交通卡 / 手机 NFC 模拟卡**：不支持作为写入目标。
* **非 4 字节 UID 或非 1K 容量的卡片**：应用会提示目标类型不受支持。
:::

### 2. 支持的写入设备 / 平台
卡片写入需要以下任一方式提供的 NFC 硬件支持：
* **Android 手机**：使用手机自带的 NFC 感应区。
* **外接 HINATA / HINATA Lite 读卡器**：通过 USB / Web 方式连接 HINATA 读卡器（支持网页版 `go.neri.moe`、Android App 等）。

---

## 写入模式说明

在写入时，HINATA Go 提供两种访问控制模式供选择：

| 模式 | 特点 | 说明 |
| :--- | :--- | :--- |
| **可再次写入 (Rewritable)** | 灵活、可修改 | 写入数据后保留可改写权限。未来若需要更新卡号或改作他用，仍可再次写入。**（推荐）** |
| **永久只读 (Permanently Read-Only)** | 防篡改、不可逆 | 写入数据后将扇区访问控制位（Access Bits）锁死为只读。一旦锁定，**任何工具都无法再改写或恢复该卡片**。选择此模式时会弹出二次安全确认。 |

::: note
无论选择哪种写入模式，卡片写入均**不会更改卡片原有的物理 UID**（仅写入对应的游戏扇区数据）。
:::

## 操作步骤

### 第一步：准备卡号

写入需要一个合法的 20 位 Access Code（通常为**非 3 开头的 20 位数字**）。你可以通过以下任一途径在 HINATA Go 中准备好该卡片：

1. **已保存的卡片**：如果卡片已在你的“收藏”或文件夹中，直接进入下一步。
2. **扫描记录**：在“扫描”页面读取过某张卡后，从历史记录中查看该卡。
3. **手动添加**：切换至 **卡片** 页面，点击右下角 **添加卡片**，输入自定义名称与 20 位 Access Code 并保存。

### 第二步：进入卡片详情并点击写入

1. 在卡片列表中点击目标卡片，进入卡片详情页面。
2. 在底部操作栏中，点击 **写入** 按钮（图标为 NFC 图标）。

### 第三步：选择写入模式并开始

1. 在弹出的「写入 MIFARE 卡片」对话框中，选择访问方式（**可再次写入** 或 **永久只读**）。
2. 点击 **开始写入**。
   * 若选择了“永久只读”，会弹出风险提示确认框，点击确认后继续。

### 第四步：贴卡写入

1. 屏幕将提示「请将 MIFARE Classic 1K 卡片贴近手机或读卡器」。
2. 将待写入的空白卡片贴近手机 NFC 天线区域，或放置在已连接的 HINATA 读卡器上。
3. 应用会自动执行以下流程：
   * 检查卡片类型
   * 检查密钥与访问控制权限
   * 写入卡片数据
   * 校验写入结果
4. 界面显示 **卡片写入并验证成功** 时，点击 **完成** 即可移开卡片。

## 常见问题排查

* **提示「卡片写入需要安卓 NFC 或已连接的 HINATA 读卡器」**：  
  请确认当前环境具备可用 NFC：若在 PC 网页端使用，请先连接并授权 HINATA 读卡器；若在手机端使用，请确认手机已开启系统 NFC 功能。
* **提示「请使用 4 字节 UID 的 MIFARE Classic 1K 卡片」**：  
  说明放置的卡片并非标准的 MIFARE Classic 1K（例如放置了交通卡、Amusement IC 或 7 字节 UID 卡片）。
* **提示「无法使用支持的密钥认证该卡片」**：  
  说明卡片对应扇区使用了未知密码加密，并非出厂默认空白卡。
* **提示「卡片已移开，或等待卡片超时」**：  
  写入期间卡片位置出现晃动或移开过早。请重新点击开始写入，并保持卡片平贴读卡器直至提示完成。
